# LED Controller

Веб-приложение для управления светодиодом на Raspberry Pi Zero 2W
(React + TypeScript + Vite).

## Возможности

- Большая SVG-лампочка: клик переключает светодиод, при включении появляется свечение с пульсацией
- Переключатель ВКЛ / ВЫКЛ; пока идёт запрос, он заблокирован и показывает спиннер
- Оптимистичное обновление; при ошибке состояние откатывается и показывается уведомление
- Опрос состояния каждые 4 секунды (останавливается в неактивной вкладке)
- Индикатор связи «Онлайн» / «Нет связи», время последнего обновления, кнопка «Обновить»
- Таймер автовыключения (1 / 5 / 10 минут) с обратным отсчётом
- Журнал из последних 10 действий

## Структура

```
src/
  api/http.ts           — экземпляр axios, API_URL, тип PromiseResponse
  api/led.ts            — getState / handleState
  hooks/useLed.ts       — вся логика: состояние, загрузка, ошибки, опрос, таймер, журнал
  components/           — Bulb, PowerButton, StatusBar, AutoOffTimer, ActionLog, Toasts, Spinner
  types.ts              — общие типы
```

## Запуск

1. Установить зависимости (нужен Node.js 18+):

   ```bash
   npm install
   ```

2. Создать файл `.env` из шаблона и указать адрес API:

   ```bash
   cp .env.example .env
   ```

   ```
   VITE_API_URL=http://192.168.1.50:8000/api
   ```

   Запросы уходят на `${VITE_API_URL}/device/raspberrypi-zero-2w/led`.
   После изменения `.env` перезапустите dev-сервер.

3. Запустить dev-сервер:

   ```bash
   npm run dev
   ```

   Откройте http://localhost:5173. Сервер слушает все интерфейсы, поэтому с телефона
   в той же сети можно открыть `http://<IP-компьютера>:5173`.

Сборка для продакшена: `npm run build`, результат лежит в папке `dist/`.

> Если API находится на другом хосте, на нём должен быть включён CORS для адреса фронтенда.
